# Posting pack: required with EVERY post, story, reel or ad

The owner has asked that every piece of content comes with everything needed to publish it,
so they never have to work anything out themselves. Never hand over a graphic or video without this.

## For every organic post, story or reel
1. **The file(s)**, sent with SendUserFile, in the order to post them, plus how to save them to the
   phone (tap the file → Save / Save to Photos).
2. **Where to post:** each platform (Instagram feed / Reel / Story, Facebook, TikTok, Google Business
   Profile) and why. Say which ones to skip and why.
3. **When:** exact day, date and time (Melbourne).
4. **Step-by-step how to post** in the app: every tap, in order (e.g. Instagram → + → Post → select
   in order → Next → caption → location → Share to Facebook ON → Share). Include stickers for Stories
   (link sticker URL, poll text), cover frame for Reels, and "pin to profile" if relevant.
5. **Caption:** copy-ready in a code block, following `knowledge/no-ai-look.md`.
6. **Hashtags:** copy-ready. Instagram allows a maximum of **5**, so give the best 5. TikTok 3–5.
   Facebook 0–2.
7. **Location tag**, accounts to tag, **alt text**.
8. **After posting:** what to do in the first hour (reply to comments, share to Story) and what to
   check after 48 hours.

## For every ad (Meta and TikTok)
1. **The creatives**: feed 1080×1350 and story 1080×1920, with the file names.
2. **Full Ads Manager build sheet**, click by click:
   - Campaign: objective, name, budget type, special ad category (none), A/B test off
   - Ad set: conversion location, performance goal, budget, start/end date and time, **audience**
     (location pin and radius, age, gender, Advantage+ audience on/off and suggestions, detailed
     targeting, languages), placements, exclusions
   - Ad: identity (Facebook Page + Instagram account), format, media per placement, **primary text,
     headline, description, call-to-action button, website URL** (with UTM), display link
   - What to do if Meta flags or rejects it
3. **2–3 copy variations** to test.
4. **Simpler alternative**: how to "Boost" it from the Instagram app if Ads Manager feels too much.
5. **Compliance check** ticked (18+, no before/after, honest claims, real prices).
6. **What good looks like** after 3 and 7 days, and what to change if it's not working.
